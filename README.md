## 📌 About Project

SBS Company Profile is a modern responsive website developed using **React.js**. 
This project is designed to present company information, services, projects, testimonials, and contact information with an interactive and user-friendly interface.

The website implements a component-based architecture using React components to create a structured, reusable, and maintainable codebase.

## ✨ Features

- Responsive company profile website
- Modern landing page design
- Hero section
- About company section
- Services showcase
- Project portfolio display
- Client testimonials
- Statistics section
- Contact information
- Navigation and smooth scrolling experience

## 🚀 Installation

Clone this repository:

git clone https://github.com/Gumiyaa/sbs-cp.git

Go to project directory:

cd sbs-cp

Install dependencies:

npm install

Run development server:

npm start

Open:

http://localhost:3000

## 📦 Build For Production

Create optimized production build:

npm run build

The build output will be generated inside:

build/
